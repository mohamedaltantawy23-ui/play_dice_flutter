# play_dice_flutter
# 🎲 Play Dice — Flutter Course, Section 2

A Flutter application demonstrating state management with `StatefulWidget` and `setState()`.

## 📌 Features
- Rolls two random dice (values from 1 to 6) using `dart:math`.
- Shows the total score dynamically.
- Reset button to set dice back to default values.
- Styled using Material 3 Dark Theme with a green color scheme.

## 🧠 Core Concept Learned
Understanding the fundamental difference between `StatelessWidget` and `StatefulWidget`, and utilizing `setState()` to trigger UI rebuilds upon user interaction.
